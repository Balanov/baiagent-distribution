# Поиск каналов — Старт первых

Короткая русская страница с двумя действиями: открыть рабочую веб-версию продукта или скачать установщик для Windows. Без анкет, вкладок и дополнительных сценариев.

## Локальный запуск

Требуется Node.js 24 или совместимая версия с Vite 7.

```bash
npm install
npm run dev
```

## Производственная сборка

```bash
npm run build
```

Готовые статические файлы появятся в `dist/`. Их можно размещать в корне `distribution.startpervyh.ru` на обычном статическом хостинге без Node.js.

## Проверка

```bash
npm run build
npm test
```

Проверка запускает временный preview-сервер и реальный Chromium. Путь к браузеру можно переопределить переменной `CHROME_PATH`. Проверяются русский оффер, две целевые ссылки, доступность веб-версии и установщика, отсутствие форм и горизонтального переполнения, первый экран на десктопе и телефоне.

Для проверки уже опубликованной страницы:

```bash
TEST_URL=https://distribution.startpervyh.ru/ npm test
```

## Целевые действия

- Веб-версия: `https://owners.startpervyh.ru/`.
- Windows: прямая ссылка на установщик релиза `v0.1.0` в GitHub Releases.

Установщик имеет размер 442 596 063 байта. SHA-256: `bbf67aed767d1f4f0c7812b88f7dae60ee689177c0577a40d4f47a9fba1d037c`.

## Структура

- `index.html` — контент и семантическая разметка;
- `style.css` — адаптивное оформление в стиле «Старта первых»;
- `public/images/` — фирменные изображения основного сайта;
- `scripts/verify.mjs` — браузерные проверки производственной сборки.
