# BAIagent Distribution 0.1.0

Первый исходный релиз local-first контура системного распространения.

## Реализовано

- Исследование продукта по публичному URL и шесть пресетов экосистемы.
- Evidence-based паспорт, допуск к партнёрскому пилоту и возврат слабых офферов в контур аналитики или реализации.
- Каталог из 21 канала с ранжированием, первым шагом, целевым событием и stop-условием.
- Бартерные предложения и персональные drafts без выдуманных цен и договорённостей.
- Локальный автопилот с машинной проверкой контракта маршрута.
- Markdown-экспорт полного потока и JSON outbox `baiagent.distribution.outbox.v1`.
- Блокировка внешних действий для продукта без читаемых первичных данных или конкретного оффера.
- Desktop IPC для нативного сохранения Markdown и JSON; унаследованная локальная Qwen и обработка выбранных документов.
- Статический веб-пакет для публикации на поддомене и CI-конфигурация.

## Проверено локально

- 448 автоматических тестов в 34 файлах.
- Production web build успешно собран.
- Живой research endpoint вернул HTTP 200 для всех шести пресетов; каждый продукт правильно распознан и получил 10 каналов.
- `npm audit --omit=dev`: 0 уязвимостей рабочих зависимостей на момент проверки.

## Ограничения релиза

- Реальные внешние коннекторы публикации ещё не подключены. Outbox не означает отправку, публикацию или выручку.
- Нативный Windows installer в текущем окружении не собран: `electron-builder` останавливается с `ENOTDIR` при копировании Electron. Исходный desktop runtime присутствует, но артефакт не заявляется как готовый.
- Публикация на `distribution.startpervyh.ru` требует отдельного DNS/hosting доступа и не следует из наличия `dist/`.
