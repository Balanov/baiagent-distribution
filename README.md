# BAIagent Distribution × Старт первых

Публичная страница агентной операционной системы доказуемого распространения инноваций. Продуктовый контур: допуск к распространению, паспорт продукта, граф каналов, партнёрские предложения, агент-оператор с подтверждением человека и атрибуция результатов.

## Локальный запуск

Требуется Node.js 24 или совместимая версия с Vite 7.

```bash
npm install
npm run dev
```

## Производственная сборка

```bash
npm run build
```

Готовые статические файлы появятся в `dist/`. Их можно размещать в корне `distribution.startpervyh.ru` на обычном static/nginx-хостинге без Node.js.

## Проверка

```bash
npm run build
node scripts/verify.mjs
```

Проверка запускает временный preview-сервер и реальный Chromium. Путь к браузеру можно переопределить переменной `CHROME_PATH`. Проверяются вкладки, все четыре статуса предпроверки, форма с имитированным ответом сервера, мобильное меню, внутренние ссылки и горизонтальное переполнение.

## Заявки

Форма отправляет данные и необязательную презентацию в существующий endpoint `https://startpervyh.ru/send_mail.php`. Endpoint поддерживает CORS и возвращает JSON. Максимальный размер файла на стороне клиента — 15 МБ.

## Структура

- `index.html` — контент и семантическая разметка;
- `style.css` — адаптивное оформление в стиле «Старта первых»;
- `main.js` — вкладки, мобильное меню, предпроверка и отправка формы;
- `public/images/` — фирменные изображения основного сайта;
- `scripts/verify.mjs` — браузерные проверки производственной сборки.
