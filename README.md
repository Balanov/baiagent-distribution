# BAIagent Distribution

**Local-first агент системного распространения: узнаёт продукт, строит проверяемый маршрут к каналам, формирует взаимный бартер и подготавливает автономный поток действий.**

Проект закрывает третий контур экосистемы `1 ⇄ 2 ⇄ 3`: после аналитики и реализации продукта он помогает довести работающее предложение до рынка. Ядро исследования унаследовано от [BAIagent Director](https://github.com/Balanov/baiagent-director); распределительный движок детерминирован и не требует облачной модели.

Веб-версия проверена публичным сценарием: исследование «Баланов.ПРО», маршрут из 10 каналов, 5 бартерных офферов, локальный автопилот и скачивание потока. CI успешно собрал Windows, Linux, macOS и веб-пакет; установка каждого нативного артефакта вручную отдельно не проверялась. Установщики не подписаны Authenticode / не нотаризованы.

## Что уже реализовано

- Запуск по любому публичному URL и пресеты шести продуктов экосистемы: Баланов.ПРО, BAIagent, BAIagent Франшиза, Свой, Паритет и Attractor.
- Evidence-based паспорт продукта: предложения, сегменты, источники и распознанный цифровой след.
- Допуск к распространению: при отсутствии первичных данных продукт возвращается к аналитике, при отсутствии оффера — к реализации и упаковке.
- 21 канал в каталоге: внутренние владельцы и региональные центры, «Старт первых», GitHub, медиа, сообщества, институты развития, закупки и международные площадки.
- Для каждого канала: обоснование, официальный URL, первый шаг, целевое событие и stop-условие.
- Бартер без выдуманных цен: вклад создателя, вклад канала, персональный draft и проверяемый результат.
- Локальный автопилот и экспорт потока в Markdown, а также машинный outbox в JSON для последующих коннекторов.
- Windows desktop: исследование, выбранные локальные документы, локальная Qwen через Ollama или `node-llama-cpp`, нативное сохранение результатов.
- Веб-версия: экспресс-исследование публичного URL, весь распределительный движок и экспорт в браузере.

## Границы автономности

Человек не является обязательным этапом. Локальные действия выполняются автоматически. Внешние чтение правил, отправка и публикация выполняются автономно **только после подключения коннектора с соответствующей областью прав**.

Текущий релиз не содержит реальных внешних коннекторов публикации: действия остаются в `waiting_for_connector`. Продукт не обходит ограничения площадок, не рассылает массовый спам, не принимает денежные обязательства и не выдаёт отправку за встречу, пилот или выручку. Каналы — это проверяемые гипотезы, а не гарантированные договорённости.

## Быстрый запуск

Требуются Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Веб-версия использует `https://baiagent.ru/xray/api/research.php` для исследования публичного сайта. Другой совместимый endpoint можно задать через `VITE_RESEARCH_ENDPOINT`.

### Локальный desktop-агент

```bash
npm run electron:dev
```

Desktop не требует оплаты облачных токенов. При отсутствии совместимой локальной Ollama приложение может скачать около 2,4 ГБ данных модели Qwen3-4B; рекомендуется 8 ГБ RAM или больше. Свежему исследованию сайтов нужен интернет, но inference и локальные документы остаются на компьютере.

Если postinstall нативной зависимости конфликтует с окружением, для веб-разработки и JS-тестов можно использовать:

```bash
npm ci --ignore-scripts
npm test
npm run build
```

Этот обход не заменяет проверку нативной desktop-сборки.

## Формат outbox

`baiagent.distribution.outbox.v1` содержит три приоритетных внешних действия, канал, требуемое право `channel:publish_or_contact`, персональный draft, целевое событие и stop-условие. Учётные данные в outbox не записываются. Начальный статус каждого действия — `waiting_for_connector`. Если продукт не прошёл допуск, outbox получает статус `blocked_by_readiness` и пустой список действий.
